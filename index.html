About VSMD

VSMD is a VS Code extension that renders Markdown files as HTML preview directly in the editor. It provides instant preview with syntax highlighting, supports dark/light mode switching, and allows full customization through custom CSS themes.

Install from the VS Code Marketplace and start previewing your Markdown files with a single click.

Custom Themes

You can create your own themes by adding theme directories to the themes folder. Each theme must follow a specific structure:

themes/ ├── your-theme/ │ ├── vsmd.json # Theme metadata │ ├── theme.css # Theme styles │ └── preview.jpg # Preview image

vsmd.json - Contains theme metadata with fields:
- name: Theme display name
- css: CSS filename (e.g., theme.css)
- image: Preview image filename
- description: Theme description

theme.css - Your CSS styles. Use the .vsmd-content-inner selector to target only the markdown content area: 

.vsmd-content-inner h1 {
  font-size: 2rem;
  color: #569cd6;
}
.vsmd-content-inner pre {
  background-color: #1e1e1e;
  border-radius: 6px;
}
.vsmd-content-inner blockquote {
  border-left: 4px solid #569cd6;
  background-color: #252526;
}

preview.jpg / preview.png - A preview image showing how your theme looks.
